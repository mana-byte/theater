## Caveats

- Spawn mode runs Régie in a detached tmux session: no attached client, so presence is absent and nothing repaints a real terminal.
- `transcript_to_bus` is bus `ts` minus the harness record `ts`; it includes harness write delay and clock granularity (ms).
- CPU excludes short-lived children (`ps`, `lsof`, `tmux`); count them via forks.
